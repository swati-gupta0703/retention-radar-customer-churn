# Retention Radar – Customer Churn Analysis & Insights

## Project Overview

Retention Radar is a customer churn analysis and prediction project focused on identifying customers who are more likely to leave an e-commerce platform.

The project uses data analysis, visualization, and machine learning techniques to understand customer behavior and identify important factors associated with churn.

## Objective

* Analyze customer data and identify churn patterns.
* Perform data cleaning and preprocessing.
* Explore relationships between customer attributes and churn.
* Build a machine learning model to predict customer churn.
* Identify key factors that may contribute to customer churn.

## Machine Learning Models

* Logistic Regression
* Random Forest

## Model Performance

**Random Forest Accuracy: 90.98%**

**Churn Recall: 64%**

Random Forest performed better than Logistic Regression and was selected as the final model.

## Key Insights

The important factors associated with customer churn included:

* Tenure
* Cashback Amount
* Warehouse-to-Home Distance
* Number of Addresses
* Day Since Last Order
* Complaints
* Satisfaction Score

## Conclusion

The project demonstrates how data analysis and machine learning can be used to understand customer churn and identify customers who may be at risk of leaving.

The Random Forest model achieved 90.98% accuracy with 64% churn recall, while features such as tenure, cashback amount, and warehouse-to-home distance were among the important factors influencing churn prediction.
